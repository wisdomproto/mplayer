# Mplayer Sites

기존 Mplayer 화면을 재사용하는 비공개 웹 플레이어입니다. Sites의 R2 `BUCKET`에 MP3와 보관함 변경 사항, 재생목록을 저장합니다. MP3는 Git과 배포 아카이브에 포함하지 않습니다.

`node build.mjs`로 Worker ESM을 빌드합니다. `.openai/hosting.json`의 Sites ID는 재사용합니다. Sites 플랫폼의 소유자 전용 접근을 유지해야 합니다. 업로드와 마이그레이션 API도 이 접근 정책에 의존합니다. 공개 사이트로 변경하기 전 별도 쓰기 권한 검사가 필요합니다.

웹에서는 재생, 탐색, 검색, 좋아요, 곡 정보 수정, 재생목록, MP3 업로드를 지원합니다. FFmpeg와 yt-dlp가 필요한 다운로드·변환·자르기는 PC 앱에서 수행합니다. 웹에서 수정한 정보는 R2 메타데이터에 반영되며 MP3 내부 태그는 다시 인코딩하지 않습니다.

`library.json`은 최초 보관함의 곡 정보·크기·SHA256와 재생목록입니다. 음원은 포함하지 않습니다. `scripts/migrate_audio.py`는 표준 입력으로만 서비스 접근 토큰을 받아 원본 크기와 SHA256을 R2 업로드 시 검증하고, 중단 후 재실행할 수 있습니다.
